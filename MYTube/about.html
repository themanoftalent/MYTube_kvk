MyTube - Mini Video Platform

Overview

MyTube is a simple YouTube-style video platform made with plain HTML5, CSS3, and JavaScript. It does not use any frameworks or backend, making it easy to learn and run locally.

Features Implemented

Core Features

  • Home page with a responsive video grid
  • Video watch page with a full HTML5 player
  • Real-time search filter by title
  • Light and dark theme toggle
  • Mobile, tablet, and desktop support

Interactive Features

  • Like button with live counter
  • Comment system that saves and displays user comments
  • “Watch Later” list stored in LocalStorage
  • Sidebar showing related videos
  • Instant updates when searching

Design Features

  • YouTube-inspired interface
  • Smooth animations and hover effects
  • Built using CSS Grid and Flexbox
  • Mobile-first responsive design
  • Accessible with semantic HTML elements

File Structure

├── js/

└── README.md           # Project description

Technologies Used

  • HTML5 (semantic elements, video tag)
  • CSS3 (Grid, Flexbox, custom properties)
  • Vanilla JavaScript (ES6+)
  • LocalStorage API for persistence

How to Run

  1. Download and extract the project folder.
  2. Open index.html in your web browser.
  3. No server setup is required; all videos load from external URLs.

Video Sources

  • Videos are hosted on Google’s public test video repository.
  • Thumbnails are taken from Unsplash (free and royalty-free).

Features Not Included

  • Video upload functionality
  • Backend or database connection
  • Recommended videos system
  • Playlists or user channels

Browser Compatibility

  • Chrome 90+
  • Firefox 88+
  • Safari 14+
  • Edge 90+

Known Issues

Currently, there are no known issues. If a search finds no results, an appropriate message appears on the screen.

Storage

The application uses LocalStorage for:

  • Theme preference (dark/light)
  • Watch Later list
  • Like counts
  • Comments

All data is stored in the browser and stays available between sessions.

Testing Instructions

  • Search: Type in the search bar on the home page.
  • Theme: Click the sun/moon icon in the header.
  • Watch Later: Click the clock icon on any video card.
  • Like: Click the thumbs-up icon on a video page.
  • Comment: Type a message and click “Comment”.
  • Navigation: Click any video to watch it.
